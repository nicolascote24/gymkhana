# Dossier client à préparer AVANT le premier message

C'est le facteur n° 1 du résultat de Gymkhana : le site a été construit sur du vrai contenu.
Prépare ces fichiers dans le projet, puis envoie le prompt de départ.

```
references/
  brief.md          ← le dossier d'information (modèle ci-dessous)
  references.md     ← une ligne par inspiration : ce que tu aimes / n'aimes pas
  inspiration-1.jpg …   (3 à 6 captures de sites ou d'images)
photo_clients/
  hero_idee.jpg     ← l'image de hero souhaitée (la meilleure photo, grande, nette)
  ancien_site.png   ← capture de l'ancien site, s'il existe
  banque_photos/    ← toutes les vraies photos du client + le logo
  video_*.mp4       ← vidéo du client, si elle existe
```

---

## Modèle de `references/brief.md`

Remplis tout ce que tu sais. Pour ce que tu ne sais pas, écris « inconnu » : le site affichera un emplacement provisoire au lieu d'inventer.

```markdown
# Banque d'informations — {{NOM_COMPLET}}

Source : {{d'où viennent ces informations : ancien site, dépliants, client…}}

## 1. Informations générales
* Nom officiel complet / nom court :
* Slogans officiels :
* Année de fondation / fondateur :
* Adresse, ville, région, accès (ex. « à 20 min de… ») :
* Installations sur place :
* Contacts (téléphones par usage, courriel, réseaux sociaux) :

## 2. Histoire / texte officiel
(Texte intégral du fondateur ou de l'ancienne page « À propos ». Les citations
seront reprises mot pour mot.)

## 3. Équipe
* Comité / direction (rôle — nom), version et date :
* Bénévoles / employés (nombre approximatif) :

## 4. Tarifs, accès et règlements
* Prix (entrée, services) et année du tarif :
* Règlements du site :

## 5. L'offre / l'activité phare
(Ce qui rend le client unique. Pour Gymkhana : la définition du sport et la
liste des épreuves avec leur description.)

## 6. Programmation / produits / services
(La plus récente disponible, avec dates, heures, lieux. Indique l'année.)

## 7. Partenaires
* Paliers / niveaux :
* Liste complète :

## 8. Charte graphique existante
* Logo (fichier), couleurs, polices de l'ancien site :

## 9. Ce qui est inconnu ou à confirmer
* (ex. dates de la prochaine édition, programmation à venir…)
```
